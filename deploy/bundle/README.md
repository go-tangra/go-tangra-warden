# warden join bundle

Generated by the gateway (Gateway operations › Modules › warden › Add).

warden keeps secret material in an existing HashiCorp Vault (not part of
this bundle). Before the first start, prepare its KV v2 mount, policy and
AppRole as in `deploy/vault-init.sh` of the warden repository, and put the
credentials and the CA of the vault's TLS certificate on this host,
readable by uid 10001:

    private/vault/role_id
    private/vault/secret_id
    private/vault/ca.pem

Then:

    docker compose up -d

`warden-bootstrap` applies the migrations, enrols the module and checks the
vault (login and a probe secret) before `warden` starts.

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys, the AppRole credentials); `.env` holds generated passwords. Keep
both on this host only. The enrolment token is valid for the lifetime chosen
in the wizard; after the first start the module renews its identity itself.
