Open **Warden → Secrets**. Pick a folder in the left pane, or **Root**, to
list what it holds: its subfolders first, then its secrets. Click a secret
to open its view.

## Find a secret

Type in **Search secrets** and press Enter. The search matches the name,
username, host, description and folder path, never the password or the
custom fields. Results span every folder you can read. Clear the search box
and search again, or pick a folder, to go back to browsing.

You only ever see secrets you have at least `viewer` access to; the counts
and pages never include the others.

## Reveal or copy the password

In the secret's view:

- the **eye** icon shows the password, and hides it again;
- the **copy** icon copies it without showing it.

Each reveal or copy is recorded in the audit trail. The shown value is kept
only while the drawer is open.

If the vault is unavailable, revealing fails with *The vault is unavailable*;
names, usernames and other details stay readable.

## Change a password

You need `editor` or `owner` access to the secret.

1. In the secret's view, click **Edit**.
2. Under **Update password**, enter the **New password** and, optionally, a
   **Comment** (for example *rotated after audit*).
3. Click **Update password**.

The new password becomes a new version. The old ones are kept.

**Edit** also changes the name, username, host URL, description and
metadata. Changing **Folder** there moves the secret; you need write access
to the target folder.

## Versions

Click **Versions** in the secret's view. Each version shows its comment (or
how it was created, for example `imported`) and its date; the current one is
marked **current**.

- **Show** reveals that version's password (audited).
- **Restore** (editors and owners, not on the current version) copies that
  password into a **new** current version, with an optional comment. History
  is never rewritten.

A version marked **material missing** has no password in the vault, for
example after restoring a backup taken without material.

## One-time codes (TOTP)

A secret can carry a TOTP seed, so the team shares the second factor as well
as the password.

- **Add**: in **Edit**, under **2FA / TOTP**, paste an `otpauth://totp/...`
  URI or a base32 seed and click **Set TOTP**. You can also fill **TOTP seed**
  when you create the secret.
- **Use**: in the secret's view, click **Show code**. The code counts down
  and refreshes by itself when it rolls over; the copy icon copies it. Each
  fetch is audited.
- **Remove**: in **Edit**, under **2FA / TOTP**, click **Remove**.

The seed itself is never shown again.

## Delete a secret

**Delete** appears in the secret's view when you own the secret and your role
includes `secrets:delete` (*Warden administrator*). Every version is
destroyed in the vault; this cannot be undone.

## Generate a password

Open **Warden → Generator**:

1. Set **Length** (8 to 128, default 20).
2. Choose the character classes: **Lowercase**, **Uppercase**, **Digits**,
   **Symbols** (at least one).
3. Choose **Source**: **Service** (generated by warden, never stored or
   logged) or **This browser** (generated locally).
4. Click **Generate**, then the copy button.

Generated passwords are not saved anywhere. Paste the result into a new
secret or into **Update password**.
